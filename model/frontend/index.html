Heat Transition Tipping Pathways

Live agent-based model of the Dutch heat transition · Limburg sample · runs in your browser
…

Each run rebuilds the dwelling population from a 1-in-100 sample of Limburg's real building stock (heat demand, energy label, ownership, insulation cost from the model's data), then simulates 2024–2050: social-housing blocks and landlords decide on cost, homeowners on a theory-of-planned-behaviour utility. This is the same engine logic as the Java model. Homeowner adoption is still being calibrated, so the heat-pump share sits below the full AnyLogic model for now.
